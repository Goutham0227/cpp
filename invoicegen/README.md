# invoicegen

Custom OOP Python library for freelancer invoice generation, time tracking, and tax calculation.

## Features

- Time entry tracking with start/end times, duration, and hourly rates
- Invoice generation with line items and subtotals
- Tax calculation supporting VAT and multiple tax rates
- Currency formatting for multiple currencies
- Client billing summaries
- Overdue invoice detection
- Weekly and monthly time summaries
